NeuroCar
LIVE SITE: https://varnikkondareddy7-ui.github.io/The-Neuro-Car/


NeuroCar is a concept car website exploring how EEG signals, machine learning, and independent safety systems might work together as part of a future vehicle interface.

The site presents the idea through an interactive experience with a 3D concept car, vehicle configurator, EEG signal simulation, safety system section, and driving simulator.

What I Learned

Through this project, I learned how to:

Build a complete website using HTML, CSS, and JavaScript.
Use Three.js to display and interact with a 3D model.
Create interactive controls, animations, and simulations.
Organize a larger website into separate sections and features.
Make a responsive interface for different screen sizes.
Work with external libraries and online assets.
Debug issues involving scripts, file paths, styling, and 3D content.
Present concepts from machine learning, neuroscience, and vehicle safety through an interactive website.

This project helped me improve my web development skills and gave me more experience turning a technical idea into a working visual prototype.
